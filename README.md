# Houzzy — каталог мебели

Адаптивная страница каталога мебельного магазина: свёрстана по макету, семантичный HTML и SCSS.

**Демо:** [https://houzzi.vercel.app](https://houzzi.vercel.app)

## Технологии

- HTML5 — семантичная вёрстка, именование по БЭМ
- SCSS — компилируется в `css/style.css` (с source maps)
- Vanilla JS — мобильное бургер-меню
- SVG-спрайт для иконок
- Без фреймворков и сборщиков — открывается как есть

## Возможности

- Адаптивный лейаут: брейкпоинты для мобильных (≤767px), планшетов (≤1439px) и десктопа
- Адаптивные изображения через `<picture>` + `srcset` с retina-вариантами (2x)
- Бургер-меню для мобильной навигации
- Кастомные стилизованные чекбоксы
- Хлебные крошки, карточки товаров со скидками и старыми ценами
- Скрывающиеся заголовки и aria-label для доступности

## Структура проекта

```
├── index.html      # страница каталога
├── css/            # скомпилированные стили + source maps
├── scss/           # исходники SCSS
├── fonts/          # шрифты
└── images/         # картинки, SVG-спрайт, retina-варианты
```

## Как запустить

Откройте `index.html` в браузере или поднимите папку любым статическим сервером:

```bash
npx serve .
```
